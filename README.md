## Project Description

The **Hospital Management System** is a Database Management System project designed to manage important hospital information in a centralized database.

The system stores and manages information related to patients, doctors, departments, appointments, admissions, medicines, prescriptions, laboratory tests, rooms, and other hospital operations.

The project helps reduce duplicate records and makes it easier to store, retrieve, and manage hospital information using SQL.
